# Menna Galal — Developer Portfolio

A responsive dark portfolio built with HTML, CSS, vanilla JavaScript, and Bootstrap 5.

## Files
- `index.html` — portfolio content and sections
- `styles.css` — custom responsive dark theme
- `script.js` — mobile navigation and scroll reveal
- `assets/` — add your CV PDF and any optional assets here

## Before publishing
1. Add your CV as `assets/menna-galal-cv.pdf`.
2. Confirm the phone number and email in `index.html`.
3. Add your real GitHub and LinkedIn links when you decide where to display them.
4. Add public project/demo/repository links only where you are allowed to share the work.
5. If you want a profile photo, we can add it later; the current hero uses a code-inspired visual so the page works without a photo.

## Run locally
Open `index.html` in a browser. For a local server, use the VS Code Live Server extension or:
`python -m http.server 8000`

Bootstrap and Google Fonts are loaded from CDNs, so an internet connection is needed for those external assets.
